# Медкарта питомцев

← [[07 Семья]] · [[07 Шкала]] · [[07 Луч — Домашние животные]]

*Модуль «Питомцы» (CLAUDE.md, п. 5.2). Здоровье питомцев — так же, как Медкарта человека в сфере 01. У каждого питомца — карточка в «40 Люди» (шаблон «Шаблон — Питомец», `тип: питомец`) и своя подпапка здесь: `Медкарта/Барсик/`. Внутри — прививки и плановые осмотры (шаблон «Обследование»: `периодичность`, `последнее`), болезни (шаблон «Проблема здоровья»), документы ветеринара (шаблон «Медицинский документ»), вес — файл `07 Барсик — Замеры.md` (`тип: замеры`, как «01 Замеры тела»: `замеры` — `"Вес, кг: N"`, `измерено`). У каждого файла — свойство `питомец: "[[Барсик]]"`; имя файла — номер сферы и имя питомца впереди: `07 Барсик — Обследование — Прививка от бешенства.md`. Сроки следующих прививок считает программа medkarta.py. Таблицы ниже собираются сами (Obsidian Bases); на сайте GitHub их не видно — там смотрите папки.*

Записи — справка для себя и для разговора с ветеринаром, а не диагноз: при тревожных признаках — сразу к врачу.

## Питомцы

```base
filters:
  and:
    - note.тип == "питомец"
views:
  - type: table
    name: Питомцы
    order:
      - file.name
      - note.вид
      - note.порода
      - note.родился
      - note.с нами
      - note.ветеринар
      - note.до
```

## Прививки и плановые осмотры

```base
filters:
  and:
    - file.inFolder("10 Сферы/07 Семья/Медкарта")
    - note.тип == "обследование"
views:
  - type: table
    name: По сроку
    order:
      - file.name
      - note.питомец
      - note.следующее
      - note.последнее
      - note.периодичность
    sort:
      - property: note.следующее
        direction: ASC
```

## Болезни

```base
filters:
  and:
    - file.inFolder("10 Сферы/07 Семья/Медкарта")
    - note.тип == "проблема"
views:
  - type: table
    name: Открытые
    filters:
      or:
        - note.статус == "открыто"
        - note.статус == "лечится"
    order:
      - file.name
      - note.питомец
      - note.статус
      - note.когда
  - type: table
    name: Наблюдение и закрытые
    filters:
      or:
        - note.статус == "наблюдение"
        - note.статус == "закрыто"
    order:
      - file.name
      - note.питомец
      - note.статус
      - note.когда
      - note.до
```
