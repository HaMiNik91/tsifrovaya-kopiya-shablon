# Луч «Название луча»

← [[{{NN}} Шкала]]

*Строгая форма — CLAUDE.md, п. 5.3. Цифры — только в свойстве `оценки`, на нижнем уровне: «Зона / Признак: N», «Зона: N», у луча без зон — «Название луча: N»; не оценено — «нет». Свойство `оценка` пишет программа. Луч без зон — одна таблица ниже. Луч с зонами — вместо неё раздел «## Зона «…»» на каждую зону, внутри при нужде «### Признак «…»» (пример — в конце файла). Хорошее идёт первым (CLAUDE.md, п. 2.9). `вопрос` — простой вопрос луча для опросника («Как в целом с …?» — скорее плохо, средне или хорошо); `точность` — пусто или «примерно» (оценка поставлена только по общему вопросу сферы; после уточнения по линейке — снова пусто). `код` — номер сферы и следующий свободный номер луча в этой сфере («01.13»); код постоянный, при переименовании луча не меняется (п. 5.4).*

## Помощники

*Чем подниматься по этому лучу: карточки из [[60 Помощники]], у которых `луч` — код этого луча (или «код / Зона» — помощник одной зоны). Подходит помощник, у которого `уровни` «N → M» и луч сейчас на уровне от N до M−1 (CLAUDE.md, п. 5.5).*

```base
views:
  - type: table
    name: Помощники луча
    filters:
      and:
        - note.тип == "помощник"
        - note.луч.startsWith(this.код)
        - note.скрыт != true
    order:
      - file.name
      - note.уровни
      - note.помощь
      - note.научность
      - note.статус
    sort:
      - property: note.уровни
        direction: ASC
```
