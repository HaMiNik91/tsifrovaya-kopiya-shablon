# Луч «Название луча»

← [[{{NN}} Шкала]]

*Строгая форма — CLAUDE.md, п. 5.3. Цифры — только в свойстве `оценки`, на нижнем уровне: «Зона / Признак: N», «Зона: N», у луча без зон — «Название луча: N»; не оценено — «нет». Свойство `оценка` пишет программа. Луч без зон — одна таблица ниже. Луч с зонами — вместо неё раздел «## Зона «…»» на каждую зону, внутри при нужде «### Признак «…»» (пример — в конце файла). Хорошее идёт первым (CLAUDE.md, п. 2.9).*
