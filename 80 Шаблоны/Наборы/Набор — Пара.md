# Набор — Пара

← [[Наборы на старте]] · [[Профиль]]

*Для двоих, которые ведут копии вместе: у каждого своя копия (оценки — личные), общее — файл «06 Наши традиции».*

Каждый партнёр создаёт свою копию из шаблона и выбирает этот набор. Внутри — всё как в «Полном»; общие планы и традиции пара записывает в «06 Наши традиции» (у каждого своя копия файла; переписать общий текст из одной копии в другую поможет Claude). Совместная копия на двоих в одном хранилище не делается: оценки по Шкале у каждого свои.
