# Мои сферы

← [[Начни здесь]] · [[Колесо баланса]]

*Ваши сферы: по умолчанию их 12, но набор — ваш. На странице заполнения, на экране «Мои сферы», можно переименовать сферу, добавить свою (с лучами), добавить луч в любую сферу, поменять порядок на колесе и скрыть сферу («не моё сейчас» — она уходит с колеса, но ничего не удаляется и возвращается одним нажатием).*

*Как это работает: страница записывает поручение в свойство `заявка` этого файла, а программа на GitHub (`nastroyka.py`, около минуты) выполняет его: переименовывает папку и исправляет все ссылки, создаёт файлы новой сферы и лучей, ставит `порядок`. Что сделано — в разделе ниже. У каждой сферы постоянный `код` — по нему программы и обновление из шаблона узнают сферу и после переименования (CLAUDE.md, п. 4.1).*

## Все сферы

```base
filters:
  and:
    - file.inFolder("10 Сферы")

  - type: table
    name: По порядку на колесе
    order:
      - file.name
      - note.код
      - note.порядок
      - note.скрыта
    sort:
      - property: note.порядок
        direction: ASC
```
