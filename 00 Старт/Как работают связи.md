# Как работают связи

← [[Начни здесь]]

Короткая справка для новичка: как файлы цифровой копии связаны между собой.

## 1. Ссылки
Название файла в двойных квадратных скобках — ссылка: `[[01 Хочу]]`. В Obsidian по ней можно нажать и перейти. Можно показать другую подпись: `[[01 Хочу|мои цели]]`. Имена файлов уникальны — они начинаются с номера сферы, поэтому ссылка всегда ведёт в нужное место.

На сайте GitHub такие ссылки не нажимаются — это особенность Obsidian.

## 2. Обратные ссылки
Если файл А ссылается на Б, то в Б это видно на панели Backlinks (Обратные ссылки). Поэтому из любого файла можно увидеть, кто на него ссылается.

## 3. Свойства
В начале файла, между строками `---`, — свойства (шапка): `тип`, `сфера`, `статус`, `обновлено` и другие. Свойство `сфера` — это ссылка на оглавление сферы, так что каждый файл связан со своей сферой. По свойствам Obsidian ищет файлы и строит таблицы. Полный список свойств — в CLAUDE.md, раздел 5.4.

## 4. Таблицы (Bases)
Блок, начинающийся с `base`, — живая таблица Obsidian Bases (Базы). Она сама собирает файлы по свойствам: например, [[Летопись жизни]] показывает все случаи из жизни по годам. Вручную её вести не нужно.

## 5. Граф
Graph view (Граф) — карта всех файлов: точки — файлы, линии — ссылки. Настроен заранее:
- обычные случаи из папок «Опыт» скрыты, чтобы не было тысячи мелких точек;
- **красная точка** — ключевой случай с отрицательным влиянием, который ещё не проработан: место для работы над собой;
- **зелёная точка** — ключевой случай, который уже проработан.

Линии от ключевого случая ведут к сферам из его свойства `влияет`. Local graph (Локальный граф) показывает связи только одного открытого файла.

## 6. Как движется информация
1. Пишу всё вперемешку во **Входящие** сферы (или в общие 01 Входящие).
2. При разборе записи раскладываются: факты → Сейчас, мысли и эмоции → Мысли, идеи → Идеи, истории → Опыт.
3. Идея → Мысли → Убеждения; параллельно → Путь (что делать).
4. Оригинал записи без изменений переезжает в **Записи**.
