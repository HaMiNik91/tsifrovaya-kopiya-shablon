# Летопись жизни

← [[Начни здесь]]

*Все случаи из жизни из папок «Опыт» всех 12 сфер — по годам. Таблица собирается сама (Obsidian Bases); на сайте GitHub её не видно. Вкладка «Периоды» — учёба, работа, жильё и другие длительные этапы по линиям. Вкладка «Ключевые» — только весомые случаи, повлиявшие на несколько сфер.*

```base
filters:
  or:
    - note.тип == "опыт"
    - note.тип == "проблема"
views:
  - type: table
    name: Вся жизнь
    order:
      - note.когда
      - file.name
      - note.сфера
      - note.вид
      - note.значимость
    sort:
      - property: note.когда
        direction: ASC
  - type: table
    name: Периоды
    filters:
      and:
        - note.вид == "период"
    order:
      - note.линия
      - note.когда
      - note.до
      - file.name
      - note.сфера
    sort:
      - property: note.линия
        direction: ASC
      - property: note.когда
        direction: ASC
  - type: table
    name: Ключевые
    filters:
      and:
        - note.значимость == "ключевое"
    order:
      - note.когда
      - file.name
      - note.сфера
      - note.влияет
      - note.влияние
      - note.проработка
    sort:
      - property: note.когда
        direction: ASC
```
