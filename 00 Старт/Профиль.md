# Профиль

← [[Начни здесь]] · [[Как со мной работать]]

*Короткие данные о владельце для настройки копии (CLAUDE.md, п. 5.2, «Профиль»). Любое поле можно оставить пустым — тогда всё работает по общим линейкам. Заполняется в первом разговоре с Claude (CLAUDE.md, раздел 11) или руками. Обновления шаблона этот файл не трогают.*

| Поле | Что писать |
|---|---|
| `год рождения` | год числом (не возраст — он устаревает) |
| `пол` | мужской, женский или пусто |
| `этап жизни` | учёба, работа, семья с маленькими детьми, взрослые дети, на пенсии — или своими словами |
| `часов в неделю` | сколько часов в неделю готовы уделять копии и работе над собой |
| `набор` | с чего начать: Полный, Лёгкий старт, Подросток, Пара ([[Наборы на старте]]) |
| `модули` | какие модули включены: Основа и дополнительные ([[Модули]]) |
| `язык` | язык копии; пока только русский |

`набор применён` и `модули включены` пишет программа `nastroyka.py` — руками не менять. После правки `набор` или `модули` Claude запускает её (CLAUDE.md, п. 5.2).
