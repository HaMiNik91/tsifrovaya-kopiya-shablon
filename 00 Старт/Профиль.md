# Профиль

← [[Начни здесь]] · [[Как со мной работать]]

*Короткие данные о владельце для настройки копии (CLAUDE.md, п. 5.2, «Профиль»). Любое поле можно оставить пустым — тогда всё работает по общим линейкам. Заполняется анкетой знакомства на странице заполнения (при первом входе; потом — экран «Обо мне»), в первом разговоре с Claude (CLAUDE.md, раздел 11) или руками. Обновления шаблона этот файл не трогают.*

| Поле | Что писать |
|---|---|
| `имя` | как к вам обращаться — страница здоровается по имени |
| `год рождения` | год числом (не возраст — он устаревает) |
| `пол` | мужской, женский или пусто |
| `страна` | где вы живёте — для валюты в учёте денег и «по закону своей страны» в ветках |
| `пара` | да или нет; нет — скрыт луч «Совместная жизнь», в опроснике — вопросы «без пары» |
| `дети` | да или нет; нет — в опроснике вопросы «без детей», зона «Свои дети» остаётся без оценки |
| `ограничения здоровья` | да или нет, без подробностей; да — у физических лучей пометка «Сначала посоветуйтесь с врачом» |
| `этап жизни` | учёба, работа, семья с маленькими детьми, взрослые дети, на пенсии — или своими словами |
| `часов в неделю` | сколько часов в неделю готовы уделять копии и работе над собой |
| `приоритеты` | коды 1–3 сфер, которые двигать первыми, по порядку: "06", "09" — ставятся в «Время и внимание» |
| `событие` | большое событие в ближайшие месяцы: переезд, новый питомец, ребёнок, нет — или своими словами; «Следующий шаг» подскажет ветку |
| `набор` | с чего начать: Полный, Лёгкий старт, Подросток, Пара ([[Наборы на старте]]) |
| `модули` | какие модули включены: Основа и дополнительные ([[Модули]]) |
| `язык` | язык копии; пока только русский |

`набор применён`, `модули включены` и `анкета применена` пишет программа `nastroyka.py` — руками не менять; `анкета пройдена` (дата и время) пишет анкета на странице. После правки профиля программу запускает GitHub Actions сам; Claude после своей правки запускает её тоже (CLAUDE.md, п. 5.2). Цикл и питомцы отдельных полей не имеют — это модули «Цикл» и «Питомцы» в `модули`.
