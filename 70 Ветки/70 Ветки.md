# Ветки событий

← [[Начни здесь]]

*Ветка — план события с началом и концом: переезд, новый питомец, беременность, позже — новая работа, ремонт, свадьба. Три фазы: **подготовка** (что узнать, купить, оформить) → **процесс** (сам день события и первые дни) → **привыкание** (первые недели и месяцы). Правила — CLAUDE.md, п. 5.6.*

**Как запустить.** Скажите Claude: «запусти ветку … , день события …». Claude возьмёт заготовку из «80 Шаблоны/Ветки», заведёт файл здесь (`ГГГГ-ММ-ДД Ветка — Тема.md`), посчитает сроки шагов от дня события, создаст шаги в «Путь» нужных сфер и задачи в Todoist (проект с именем ветки). Дальше программа `vetki.py` сама считает фазу, сделанное и просроченное (раздел «Сейчас» в ветке).

**Как закончить.** «Закончи ветку …» — ветка получает `статус: закончена`, а в «Опыт» главной сферы появляется период: событие попадает в [[Летопись жизни]]. Выводы — в «Выводы» сферы.

**Заготовки:** [[Ветка — Переезд]] · [[Ветка — Новый питомец]] · [[Ветка — Беременность]]. Новую заготовку Claude делает по [[Шаблон — Ветка]].

```base
views:
  - type: table
    name: Идут сейчас
    filters:
      and:
        - note.тип == "ветка"
        - note.статус == "идёт"
    order:
      - file.name
      - note.вид
      - note.фаза
      - note.день события
      - note.сферы
    sort:
      - property: note.день события
        direction: ASC
  - type: table
    name: Закончены
    filters:
      and:
        - note.тип == "ветка"
        - or:
            - note.статус == "закончена"
            - note.статус == "отменена"
    order:
      - file.name
      - note.вид
      - note.статус
      - note.когда
      - note.до
    sort:
      - property: note.до
        direction: DESC
```
