# Помощники по лучам

← [[Начни здесь]]

*Библиотека помощников: чем подниматься по линейкам Шкалы. Один помощник — одна карточка `Помощник — Название.md` в этой папке (шаблон «Шаблон — Помощник»; правила — CLAUDE.md, п. 5.5). Каждый помощник привязан к одному лучу (`луч` — код луча) и к отрезку линейки (`уровни` — «N → M»): он подходит, когда луч сейчас на уровне от N до M−1, — новичку не показываются советы для верхних уровней. Три вида помощи: **совет** — что знать; **практика** — что делать (шаг в «Путь», привычка в менеджере задач); **инструмент** — интерактивная страница или таблица. Помощники луча видны и в самом луче, раздел «Помощники». Таблицы ниже собираются сами (Obsidian Bases); на сайте GitHub их не видно — там смотрите саму папку.*

Папка лежит отдельно от «80 Шаблоны»: шаблоны скрыты от поиска и таблиц Obsidian, а помощники должны быть видны.

```base
views:
  - type: table
    name: По лучам
    filters:
      and:
        - note.тип == "помощник"
        - note.скрыт != true
    groupBy:
      property: note.луч
      direction: ASC
    order:
      - file.name
      - note.уровни
      - note.помощь
      - note.научность
      - note.сфера
      - note.статус
    sort:
      - property: note.уровни
        direction: ASC
  - type: table
    name: По виду помощи
    filters:
      and:
        - note.тип == "помощник"
        - note.скрыт != true
    groupBy:
      property: note.помощь
      direction: ASC
    order:
      - file.name
      - note.луч
      - note.уровни
      - note.научность
      - note.сфера
  - type: table
    name: Не для меня
    filters:
      and:
        - note.тип == "помощник"
        - note.скрыт == true
    order:
      - file.name
      - note.луч
      - note.уровни
      - note.помощь
```
