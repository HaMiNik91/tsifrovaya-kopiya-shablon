# Цифровая копия

Ваша «электронная версия» по 12 сферам жизни: здоровье, эмоции, интеллект, характер, духовность, пара, семья, друзья, профессия, финансы, хобби, качество жизни. У каждой сферы — лучи (её части), у каждого луча — линейка из 10 уровней: от худшего (1) до идеала (10). Вы находите себя на линейке, и становится видно, где вы сейчас, какой шаг следующий и какой сфере отдать время и внимание в первую очередь.

Всё хранится в **вашем закрытом хранилище** на GitHub — только у вас. Заполнять можно нажатиями на странице, без программ и без чата. Claude нужен для разговора о жизни (разбор дня, планы, убеждения) и для больших изменений.

## Как начать

**Проще всего — пошаговая страница:** https://tsifrovaya-kopiya.misha-kharinin.workers.dev/start — она проведёт по всем шагам ниже, с кнопками и подсказками на русском.

**1. Аккаунт на GitHub.** GitHub — сайт, где будет лежать ваше хранилище. Аккаунт бесплатный. Если он уже есть — войдите и переходите к шагу 2.

Откройте в обычном браузере (Chrome, Safari) https://github.com/signup и заполните по очереди:
- **Email** (Почта) — ваша почта; к ней придёт код.
- **Password** (Пароль) — не короче 15 знаков или не короче 8 с цифрой и маленькой буквой.
- **Username** (Имя аккаунта) — латиницей, без пробелов, например `ivan-petrov`. Оно будет в адресе вашего хранилища. Если занято, сайт подскажет — допишите цифры.
- **Your Country/Region** (Ваша страна) — выберите из списка.

Нажмите **Continue** (Продолжить) или **Create account** (Создать аккаунт). Сайт попросит доказать, что вы человек: нажмите **Verify** (Проверить) и выполните простое задание с картинками. Затем откройте письмо от GitHub и впишите код из него. Если сайт задаёт вопросы о вас (команда, интересы) — их можно пропустить кнопкой **Skip** (Пропустить); на вопрос о плане выберите бесплатный (**Free**). Готово, вы вошли.

**2. Своя копия.** Откройте страницу этого шаблона (на ней вы сейчас читаете этот текст) и нажмите зелёную кнопку **Use this template** (Использовать этот шаблон) → **Create a new repository** (Создать новое хранилище). Впишите имя хранилища, например `tsifrovaya-kopiya` (латиницей; занято — любое другое). Обязательно выберите **Private** (Закрытое): ваши оценки и записи будут видны только вам. Галочку **Include all branches** (Включить все ветки) не ставьте. Нажмите **Create repository** (Создать хранилище) — откроется ваше хранилище.

**3. Страница заполнения.** Откройте в обычном браузере (не во встроенном окне приложения) и пройдите вход в одном окне:

https://tsifrovaya-kopiya.misha-kharinin.workers.dev

- Нажмите **«Войти через GitHub»**, на GitHub — **Authorize** (Разрешить).
- В первый раз нажмите **«Поставить на хранилище»**: выберите **Only select repositories** (Только выбранные хранилища), отметьте своё хранилище и нажмите **Install** (Установить). У приложения есть право только на файлы этого хранилища.
- Откроется колесо сфер.

**4. Оценки.** Колесо → сфера → луч → зона → линейка из 10 уровней. Нажмите уровень, который про вас сейчас, и **«Моя оценка — N»**. Всё выше (зоны, лучи, сферы, колесо) страница считает сама. Не подходит текст уровня — **«Изменить уровень»** и напишите своими словами. Под оценкой — **«Шаг вверх»**: что сделать, чтобы подняться на ступень; его можно добавить в свой «Путь».

**5. Время и внимание.** На колесе внизу — **«Время и внимание»**: для каждой сферы важность (1–5), место в приоритетах (не больше трёх сфер) и сколько часов внимания в неделю. Как выбирать — `00 Старт/Время и внимание.md`.

**6. Claude (по желанию).** В приложении Claude подключите GitHub к своему аккаунту и в новом чате напишите:

> Подключи моё хранилище <ваш-аккаунт>/<имя-хранилища>, прочитай README.md и CLAUDE.md и познакомься со мной.

Claude спросит, как с вами говорить, и запишет это в `00 Старт/Как со мной работать.md`. Дальше можно рассказывать ему день, разбирать сферы, планировать неделю.

**7. Obsidian (по желанию).** Чтобы читать все файлы как связанную тетрадь (ссылки, таблицы, граф), откройте хранилище в бесплатной программе Obsidian. Claude поможет настроить, если захотите.

## Вопросы

- **Кто видит мои оценки?** Только вы и те, кому вы сами дадите доступ к хранилищу. Страница заполнения ничего у себя не хранит: она читает и пишет файлы вашего хранилища от вашего имени.
- **Шаблон обновился?** Откройте в своём хранилище вкладку **Actions** (Действия) → **«Обновить из шаблона»** → **Run workflow** (Запустить) → ещё раз **Run workflow**. Новые правила, программы и линейки придут, а ваши оценки, свои правки уровней, записи и журнал останутся. Что пришло и что осталось вашим — в «00 Старт/Обновления из шаблона». Можно и попросить Claude: «обнови копию из шаблона».
- **Новый телефон?** Откройте страницу и войдите снова — всё на месте.
- **Передумал с оценкой?** Нажмите другой уровень или «Снять оценку». Все прошлые версии хранит история GitHub.
- **Не открывается или не сохраняется?** Войдите заново. Если не помогло — проверьте, что приложение стоит на вашем хранилище: https://github.com/settings/installations

Последнее обновление: пошаговая страница «Как начать» (/start) и ссылка на неё с экрана входа.
