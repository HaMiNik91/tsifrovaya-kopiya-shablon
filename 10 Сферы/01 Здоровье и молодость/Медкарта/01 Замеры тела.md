# Замеры тела

← [[01 Медкарта]]

*Цифры — только в шапке, свойство `замеры`: строка `"Что, единица: число"`; не измерено — `нет` (строка остаётся). `измерено` — дата последних замеров. Ставит Claude по словам владельца. История — из Git (каждый коммит с новыми цифрами — точка на графике). Свойство `расчёт` пишет программа `medkarta.py`, руками не правится: индекс массы тела, талия к росту, доля жира по способу ВМС США (US Navy: талия, шея, рост) — для зоны «Телосложение» в [[01 Луч — Молодость тела]].*


**Как мерить** (мягкой лентой, утром, до еды):
- талия — на уровне пупка, на спокойном выдохе, живот не втягивать;
- шея — под кадыком;
- грудь — по соскам, на спокойном выдохе;
- бёдра (ягодицы) — по самой широкой части;
- плечо — середина между плечом и локтем, рука расслаблена;
- бедро — под ягодичной складкой;
- голень — по самой широкой части.
