# Медкарта

← [[01 Здоровье и молодость]] · [[01 Шкала]] · [[01 Луч — Исправность тела]]

*Медицинские факты сферы 01. Истории жизни — в «Опыт», здесь только медицина. На каждую проблему — своя подпапка с главным файлом того же имени; анализы, снимки и заключения — отдельными файлами рядом (`01 ГГГГ-ММ-ДД Что это.md`, свойство `относится`). Статус проблемы: открыто → лечится → наблюдение → закрыто. Таблицы ниже собираются сами (Obsidian Bases); на сайте GitHub их не видно — там смотрите папки.*

## Главное

- [[01 Карта тела]] — всё тело по системам: что не беспокоит, что беспокоит, что не проверено; проценты считает программа.
- [[01 Замеры тела]] — рост, вес, обхваты; расчёт телосложения — программа.
- **Плановые обследования** — проверки без жалоб, у каждой срок следующей (папка «Плановые обследования»).

## Проблемы

```base
filters:
  and:
    - file.inFolder("10 Сферы/01 Здоровье и молодость/Медкарта")
    - note.тип == "проблема"
views:
  - type: table
    name: Открытые
    filters:
      or:
        - note.статус == "открыто"
        - note.статус == "лечится"
    order:
      - file.name
      - note.статус
      - note.когда
      - note.луч
      - note.обновлено
    sort:
      - property: note.обновлено
        direction: DESC
  - type: table
    name: Наблюдение
    filters:
      and:
        - note.статус == "наблюдение"
    order:
      - file.name
      - note.когда
      - note.луч
      - note.обновлено
  - type: table
    name: Закрыто
    filters:
      and:
        - note.статус == "закрыто"
    order:
      - file.name
      - note.когда
      - note.до
    sort:
      - property: note.когда
        direction: DESC
```

## Плановые обследования

```base
filters:
  and:
    - file.inFolder("10 Сферы/01 Здоровье и молодость/Медкарта")
    - note.тип == "обследование"
views:
  - type: table
    name: По сроку
    order:
      - file.name
      - note.следующее
      - note.последнее
      - note.периодичность
    sort:
      - property: note.следующее
        direction: ASC
```
