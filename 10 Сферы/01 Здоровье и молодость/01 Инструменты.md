*Инструменты сферы: тесты, опросники, вопросы вдвоём, списки для разговора, взгляд со стороны. Каждый инструмент — карточка `01 Инструмент — Название.md` в папке «Инструменты»; каждое прохождение — отдельный файл `01 ГГГГ-ММ-ДД Тест — Название.md` там же. Результат — снимок на дату, а не ярлык. Сюда же попадают инструменты других сфер, у которых эта сфера отмечена в `влияет`. Таблицы ниже собираются сами (Obsidian Bases); на сайте GitHub их не видно — там смотрите саму папку «Инструменты».*

```base
views:
  - type: table
    name: Инструменты
    filters:
      and:
        - note.тип == "инструмент"
        - file.hasLink("01 Здоровье и молодость")
    order:
      - file.name
      - note.вид
      - note.научность
      - note.последнее
      - note.следующее
      - note.сфера
    sort:
      - property: note.следующее
        direction: ASC
  - type: table
    name: Прохождения
    filters:
      and:
        - note.тип == "результат"
        - file.inFolder("10 Сферы/01 Здоровье и молодость/Инструменты")
    order:
      - file.name
      - note.когда
      - note.инструмент
      - note.результаты
    sort:
      - property: note.когда
        direction: DESC
```
